# Handoff: ApplyTrack
_2026-07-16 — CRUD, MUI dark theme, rich text description, card view with filters_

## Goal
Full-stack job application tracker: React + MUI frontend, NestJS + TypeORM + PostgreSQL backend.

## Current state

### Frontend (`frontend/`)
- **MUI v9** — dark theme (`mode: 'dark'`), primary `#3B82EF`, backgrounds in `colors.ts`.
- **Theme** — `theme/colors.ts` (single source of truth), `theme/theme.ts` (MUI `createTheme`).
- **Layout** (`Layout.tsx`) — sidebar (200px) with Home (`/`) and Applications (`/applications`) nav. Active nav uses `match()` for path detection. Home button: default `colors.muted` text/icon, hover/selected-hover → `colors.background` bg + `colors.primary` text. FAB + create dialog in Layout so visible on all pages.
- **Home page** (`ApplicationsList.tsx`) — MUI Table with sortable columns (Company, Role, Status, Link, Applied Where, Interview Date, Applied, Actions). Description column removed. Status as colored dot + text, click opens inline Menu. Calendar sidebar (sticky) with upcoming interviews below. Default sort: status priority (interviewing → applied → offer → rejected), then appliedAt desc.
- **Applications page** (`ApplicationsCards.tsx`) — Card grid view at `/applications`. Each card shows: date (top-right, muted), company + role on one line (body1, dot separator), status dot + label, Via, Interview date. Filter panel above cards: search text input, status chip toggles (All/Applied/Interviewing/Offer/Rejected), sort dropdown (Company/Role/Status/Applied/Interview), direction toggle. Filtering/sorting via `useMemo`.
- **Detail page** (`ApplicationDetail.tsx`) — `/applications/:id`. All fields with `wordBreak: 'break-word'`. Description rendered as HTML via `dangerouslySetInnerHTML`. Delete navigates back with `navigate(-1)`.
- **Rich text description** (`ApplicationForm.tsx`) — ReactQuill (Quill 2, `react-quill-new`) instead of plain multiline TextField. Toolbar: H1-H3, bold, italic, underline, strike, text/background color, ordered/bullet lists, align, blockquote, code-block, link, clean. Styled for dark theme (`.ql-toolbar`/`.ql-container` bg `elevation`, text `text`, strokes/fills `text` → `primary` on hover/active). Empty HTML (no text content after stripping tags) saved as `undefined`. Header dropdown uses string values `['1', '2', '3', false]` to match Quill 2 snow theme CSS `[data-value]` selectors.
- **RefreshContext** (`useRefresh.ts`) — `{ refresh, version }` — version increments after create/delete, pages re-fetch via `useCallback([version])`.
- **LocalizationProvider** in `App.tsx` (wraps entire app) — DatePicker works in create dialog.
- **Port** — Vite on `:3000`, proxy `/api` → `localhost:3001`.

### Backend (`backend/`)
- **NestJS + SWC** — build with `npx nest build` (~100ms), run with `node dist/main.js`.
- **TypeORM** — `synchronize: true`, entity `Application` with `description` (text, nullable, stores HTML), `link` (varchar, nullable), `appliedWhere` (varchar, nullable).
- **API** — `GET/POST/PATCH/DELETE /api/applications`. DTOs with validation (`class-validator`). CORS enabled.
- **Port** — `:3001`. `.env` loaded in `main.ts`.

### Database
- **PostgreSQL 16 Alpine** in Docker, port `5433`.

## Key decisions
- **ReactQuill (Quill 2) for description** — preserves rich text formatting (bold, italic, etc.) on paste. Stored as HTML. Stripped to plain text in list/card views.
- **`dangerouslySetInnerHTML` in detail view** — renders HTML description safely.
- **Header dropdown values as strings** `['1', '2', '3', false]` — Quill 2 snow theme's CSS uses `[data-value="1"]` selectors to display "Heading 1"/"Heading 2"/"Heading 3" labels; numeric values would not match CSS selectors.
- **Status filter chips + search + sort** in card view — all client-side via `useMemo`, same pattern as table sort.
- **Description column removed from table** — too cluttered; rich text also doesn't fit in a table cell.
- **Description removed from cards** — keeps cards minimal; only shown in detail view.
- **`Start-Process` for Vite/Nest** — `npx vite` and `node dist/main.js` must run as background processes; direct shell commands timeout.

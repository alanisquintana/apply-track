# Handoff: ApplyTrack
_2026-07-15 — CRUD working, MUI dark theme, sidebar layout_

## Goal

Full-stack job application tracker: React + MUI frontend, NestJS + TypeORM + PostgreSQL backend.

## Current state

### Frontend (`frontend/`)
- **MUI v5** — replaced antd entirely. Dark theme (`mode: 'dark'`), primary `#3b82f6` (vibrant blue), backgrounds in muted dark blues (`#0b0d14`, `#171d2e`).
- **Theme split** — `theme/colors.ts` (raw color values), `theme/theme.ts` (MUI `createTheme` with component overrides). `colors.ts` has no MUI imports.
- **Layout** — sidebar-only (220px, `colors.elevation` bg, no AppBar). `Layout.tsx` wraps routes with `<Drawer>` + `<main>`. Thin colored divider (`rgba(59,130,246,0.1)`) between sidebar and content.
- **Nav** — single "Home" item in sidebar. Default text white, selected text `primary`, hover bg `colors.background`.
- **Table** — MUI `Table` with sortable columns (Company, Role, Status, Description, Interview Date, Applied, Actions). Status is a colored dot + text (no Chip), click opens inline Menu to change status. Description/interview date from backend.
- **Calendar sidebar** — `DateCalendar` (sticky, 300px) with `PickerDay` + `Badge` dot on interview dates. Aligned with table top.
- **CRUD** — create/edit via `Dialog` + `ApplicationForm` (TextField, Select, DatePicker). Delete via confirmation `Dialog`. Snackbar for success/error.
- **Home page** — heading "Home", 👋 subtitle "Here you can manage all your job applications", colored divider, then table + calendar.
- **Port** — Vite on `:3000`, proxy `/api` → `localhost:3001`.
- **Data validation** — interview date must be >= applied date. Auto-promote to "interviewing" if interviewDate set while status is "applied".

### Backend (`backend/`)
- **NestJS + SWC** — build with `npx nest build` (~100ms), run with `node dist/main.js`.
- **TypeORM** — `synchronize: true`, entity `Application` with `description` (text, nullable) and `interviewDate` (date, nullable).
- **API** — `GET/POST/PATCH/DELETE /api/applications`. DTOs with validation (`class-validator`). CORS enabled.
- **Port** — `:3001`. `.env` loaded in `main.ts` via `dotenv.config()`.

### Database
- **PostgreSQL 16 Alpine** in Docker, port `5433` (local Windows PG occupies `5432`).

## Key decisions

- **MUI over antd** — MUI is more maintained, better DX with `sx` prop, theming is cleaner.
- **Dark theme only** — no light mode toggle; reduces complexity.
- **Sidebar-only layout** — no AppBar/top bar. Project name + nav in sidebar. More minimal.
- **`colors.ts` + `theme.ts` split** — colors are raw values with no MUI dependency; theme overrides are separate.
- **`background.paper = colors.elevation`** — all Paper/Dialog/Menu components auto-use this color without explicit props.
- **Colored dividers over borders** — thin blue-tinted lines (`rgba(59,130,246,0.1)`) instead of standard gray borders. More cohesive with theme.
- **Status as dot + text** — replaced colored Chips with minimalist dot + label for cleaner look.
- **SWC builder** — ~100ms build vs ts-node seconds.
- **TypeORM synchronize** — no migration files for dev; will add before production.
- **Kill processes before restart** — avoid EADDRINUSE; `Get-Process node | Where-Object CommandLine -match "vite" | Stop-Process`

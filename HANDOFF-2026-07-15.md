## Key decisions

- **TypeORM synchronize:true** — no migration files for dev speed; will add proper migrations before production
- **Vite proxy over CORS in prod** — dev uses Vite proxy `/api` → `:3001`; CORS is also enabled on backend
- **fetch over axios** — fewer deps, modern API
- **Inline forms over modals** — simpler state management for create/edit
- **Custom CSS over framework** — no extra dependencies, ~3KB output
- **Root package.json with `--prefix`** — simple delegation without workspace complexity
